# Product Requirements Document

## Product

A premium portfolio and lead-generation website for Shyam Studio in Nagpur.

## Audiences

- Couples planning wedding photography.
- Families needing portraits, ceremonies, albums, or video.
- Local businesses needing product, brand, or event photography.
- Visitors searching for the studio, contact details, or directions.

## User journeys

### Discover and enquire

Home → Services → Portfolio → Contact → WhatsApp/call/form → confirmation page.

### Find the studio

Home or Contact → location card → Google Maps directions link.

### Owner updates content

Admin login → dashboard → upload images/edit fields → preview draft → publish → revalidate public pages.

## Content sections

1. Hero: short positioning statement, one primary CTA, one secondary CTA.
2. About: concise studio story and working style.
3. Services: wedding, portrait, event, product, travel, and studio photography; owner may rename or remove categories.
4. Portfolio: curated projects with category filters.
5. Testimonials: owner-approved quotes only.
6. Team: optional until names and portraits are supplied.
7. Packages: optional until prices and inclusions are approved.
8. Journal: optional SEO content area.
9. Contact: verified phone, WhatsApp, email, hours, address, map, enquiry form.

## Non-goals for v1

- Online payment checkout.
- Customer login portal.
- Automatic quotation generation.
- Scraping Google reviews or photos.
- Publishing unverified map or directory data.

## Success metrics

- Enquiry form completion rate.
- WhatsApp and call CTA clicks.
- Direction-link clicks.
- Portfolio engagement.
- Core Web Vitals and mobile bounce rate.
